# 金格伦商业计划书 AI 研究工作流

本仓库用于研究湖南金格伦公司公开资料，并围绕公开信息打磨两个新商业计划书方向：

- A. AI 低空经济无人机物流平台 + 液流电池光储充换城市综合服务站
- B. AI + 储能工业 4.0 智慧工厂方案

## 工作流目录

```text
01_public_research/      原始公开资料归档
02_source_cards/         结构化资料卡片
03_concept_cards/        概念、假设、商业模式卡片
04_competitor_cases/     竞品、标杆、案例研究
05_bp_drafts/            商业计划书草稿
06_outputs/              对外交付版材料
prompts/                 可复用提示词
.agents/skills/          面向 Agent 的工作技能说明
```

## 资料规则

所有资料必须保留以下字段：

- 标题
- 来源
- 发布时间
- 原文链接
- 摘要
- 关键事实
- 与商业计划书方向的关系
- 待核实事项

严禁编造数据。没有公开依据的信息必须标记为“待核实”。引用公开报道、公众号文章、官网内容时，应优先保留原文链接和发布时间；无法确认发布时间时，标记为“待核实”。

## 建议文件命名

公开资料原文或摘录：

```text
YYYY-MM-DD_来源_标题.md
```

资料卡片：

```text
YYYY-MM-DD_主题_资料卡.md
```

概念卡片：

```text
concept_概念名称.md
```

竞品案例：

```text
case_公司或项目名称.md
```

商业计划书草稿：

```text
bp_A_方向名称_v001.md
bp_B_方向名称_v001.md
```
